# Counter

> 🟡 Practice `useState` and event handling — write this yourself.

![demo](https://flaviocopes.com/images/react-example-counter/output.gif)

Implement the counter shown above using React Function Components.

## Requirements

- [ ] Use `useState` to manage the count
- [ ] Four buttons to increment by 1, 10, 100, and 1,000
- [ ] One label to display the current count
- [ ] One button to reset the count to 0
- [ ] (optional) Add a decrement button
- [ ] (optional) Apply styles to make it look good
