# Color Components

> 🟢 Practice component composition and state lifting.

## Description

![color_components](hw2.gif)

## Requirements

- [ ] Two controlled components: one to select which color component, one to choose the color
- [ ] The color component should be a single reusable component (square with background color and name)
- [ ] When the name is changed, it should be reflected in the selector component
- [ ] Use component **composition patterns** (`children` or named slots) for the layout
