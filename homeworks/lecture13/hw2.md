# Interactive Layout

> 🟡 Practice `useState`, `useRef`, and event handling.

![layout](./layout.png)

## Requirements

- [ ] Create the layout similar to the phone screen above
- [ ] Every button is clickable and shows a visible effect (e.g., counter, toggle, color change)
- [ ] Use Function Components with `useState` for interactive state
- [ ] Use `useRef` for at least one interaction (e.g., focus an input, scroll to element)
