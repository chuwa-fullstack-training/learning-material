## Requirements

### Frontend-Backend Integration

- [ ] Connect React frontend to your Express backend API
- [ ] Set up CORS properly
- [ ] Create an API service layer (centralized fetch with auth headers)
- [ ] Handle loading, error, and success states properly
- [ ] Use Redux Toolkit with `createAsyncThunk` for async actions

### TypeScript

- [ ] Write your React code in **TypeScript** (`.tsx` files)
- [ ] Define interfaces for: Todo, API response, component props
- [ ] Type your custom hooks and Redux slices

### Testing

- [ ] Write at least **3 test cases** using React Testing Library:
  - One render test (component displays correctly)
  - One user interaction test (add/toggle/delete a todo)
  - One async test (loading state or API mock)
- [ ] (Bonus) Try the "test-first" workflow: write a test, then let AI implement the component to pass it
