Array length

  • arr.length — read it
  • arr.length = 0 — clears the array
  • arr.length = 10 — extends with empties
length.js
var arr = [1,2,3,4,5];

arr.length = 3;
console.log(arr); // [1, 2, 3]

arr.length = 0;
console.log(arr); // []

arr.length = 10;
console.log(arr); // [empty × 10]

Iterating over arrays

  • for...in — iterates enumerable keys (use with caution on arrays)
  • for...of — iterates values directly (preferred)
  • forEach(fn) — callback per element, no return value
  • map() — transform each element → new array
  • filter() — keep elements passing a test → new array
  • reduce() — accumulate to a single value
map / filter / reduce are introduced in ES6 and are the functional-programming idioms you'll see everywhere.
