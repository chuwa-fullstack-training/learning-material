ai-policy.matrix

What to do yourself vs. what AI can help with

🔴 Must do by hand

  • Closures, scope, async
  • Core algorithm logic
  • The feeling of being "stuck" = where real understanding happens

🟢 AI-assisted OK

  • Boilerplate code, config files
  • Save time for architectural thinking

🟡 Must deeply understand

  • System design, architecture decisions
  • AI can write code, but "why this design" must be built by you

⚪ Safe to skip

  • Memorizing specific API parameters
  • Just look up the docs when needed

assessment-methods.md
how we measure learning
proof of understanding

Assessment methods

  • Learning Log — Awareness phase: a journal of blockers, attempts, and resolution.
  • AI Comparison — Comparison phase: your solution first, then AI's, then a comparison report.
  • AI Usage Log — Ownership phase: document where AI helped and what judgments you made.
  • Mini Mock — a no-AI live assessment at the end of each phase.
  • Code Review — final project mid-term + final live code walkthrough.
The goal isn't how much code you produce — it's the dual ability to solve problems independently and leverage AI effectively.
