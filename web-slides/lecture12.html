React

  • A JavaScript library for building user interfaces
  • Developed and maintained by Meta (Facebook)
  • Used for SPAs, mobile (React Native), desktop (Electron)
  • Component-based: a component is a reusable piece of UI
  • Declarative: describe what the UI should look like, React handles DOM updates
  • Uses JSX — a syntax extension to write HTML in JavaScript

JSX

  • A syntax extension to JavaScript — looks like HTML, compiles to JS
  • Must have one root element (or use <>...</> fragment)
  • Use className instead of class, htmlFor instead of for
  • Use {'{}'} to embed JavaScript expressions
jsx.jsx
const element = <h1>Hello World</h1>;

// Compiles to:
const element = React.createElement(
  'h1', null, 'Hello World'
);

Function Components + Props

  • A function component is a JavaScript function that returns JSX
  • Props are read-only inputs passed from parent to child
Greeting.jsx
function Greeting({ name, role }) {
  return (
    <div>
      <h1>Hello, {name}!</h1>
      <p>Role: {role}</p>
    </div>
  );
}

// Usage
<Greeting name="Alice" role="Admin" />
Props flow one way: parent → child. This is called "uni-directional data flow."

useState — Managing State

state.jsx
import { useState } from 'react';

function Counter() {
  const [count, setCount] = useState(0);
  return (
    <div>
      <p>Count: {count}</p>
      <button onClick={() => setCount(count + 1)}>+1</button>
    </div>
  );
}
  • State is private to the component
  • Calling setState triggers a re-render
  • setState is asynchronous — React batches updates

Event Handling

event-handling.jsx
function SearchBox() {
  const [query, setQuery] = useState('');

  const handleChange = (e) => {
    setQuery(e.target.value);
  };

  return (
    <div>
      <input value={query} onChange={handleChange} />
      <p>Searching for: {query}</p>
    </div>
  );
}
  • React uses Synthetic Events — a cross-browser wrapper around native events
  • Use onChange, onClick, onSubmit — camelCase, not lowercase

Conditional Rendering

UserGreeting.jsx
function UserGreeting({ isLoggedIn, name }) {
  // 1. if/else (for complex logic)
  if (!isLoggedIn) return <p>Please log in.</p>;

  return (
    <div>
      {/* 2. && operator (show or hide) */}
      {name && <h1>Welcome, {name}!</h1>}
      {/* 3. Ternary (either/or) */}
      <span>{name === 'Admin' ? '👑' : '👤'}</span>
    </div>
  );
}

Lists and Keys

UserList.jsx
function UserList({ users }) {
  return (
    <ul>
      {users.map(user => (
        <li key={user.id}>{user.name}</li>
      ))}
    </ul>
  );
}
  • Use map() to render lists
  • Every list item needs a unique key prop — helps React identify what changed
Never use array index as key if the list can be reordered or filtered — React will misidentify items and get the diff wrong.

Passing Data Up: Callback Props

Parent.jsx
function Parent() {
  const [items, setItems] = useState([]);

  const handleAdd = (newItem) => {
    setItems([...items, newItem]);
  };

  return <Child onAdd={handleAdd} />;
}

function Child({ onAdd }) {
  return <button onClick={() => onAdd('New Item')}>Add</button>;
}
Parent passes a callback function as a prop → Child calls it to send data upward.

Class Components: Quick Overview

Here is the minimum you need to read them:

class Counter extends React.Component {
  constructor(props) {
    super(props); this.state = { count: 0 };
  }

  render() {
    return (
      <div>
        <p>{this.state.count}</p>
        <button onClick={() => this.setState({ count: this.state.count + 1 })}>+1</button>
      </div>
    );
  }
}

the official mental model

How to Think in React

  • 1. Break the UI into components — draw boxes around each piece
  • 2. Build a static version first — props only, no state
  • 3. Identify the minimal state — what data changes over time?
  • 4. Decide where state lives — find the common parent
  • 5. Add interactivity — event handlers that call setState
  • 6. Style it — CSS, CSS modules, or a component library
Practice this model on every homework — it's the process, not just the syntax, that makes you a React developer.
